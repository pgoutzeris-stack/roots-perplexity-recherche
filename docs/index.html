Perplexity-Recherche einrichten

Anderes Betriebssystem

Die Einrichtung ist für macOS gebaut. Auf diesem Gerät laufen die Befehle nicht.

1 Perplexity-Key anlegen

Jede Person nutzt einen eigenen Key. Damit ist der Verbrauch pro Person sichtbar.

Eine Suche kostet rund 1 Cent, eine Nachfrage wenige Cent. Ein Deep-Research-Call 50 Cent bis 2 Dollar.

  Perplexity-Konsole öffnen
2 Einrichtung starten
  1. Terminal öffnen: Cmd + Leertaste, „Terminal", Enter
  2. Befehl einfügen mit Cmd + V, dann Enter
  3. Den sechs Schritten folgen, Key beim Prompt einfügen
curl -fsSL https://raw.githubusercontent.com/pgoutzeris-stack/roots-perplexity-recherche/main/install/setup.sh | bash
Was dabei passiert

Voraussetzungen prüfen · fehlendes Node.js ohne Adminrechte nach ~/.roots/node · Recherche-Server festinstallieren · Key prüfen und in ~/.roots/perplexity-key ablegen · Plugin registrieren · Serverstart verifizieren

3 Claude neu starten

Claude mit Cmd + Q komplett beenden und wieder öffnen. Erst danach lädt der Recherche-Server den Key.

4 Prüfen

In Claude eintippen:

/perplexity-status

Erwartet werden sechs Zeilen: Key-Datei, Plugin, Node.js, API, Serverpaket, Serverstart mit 4 Werkzeugen.

Fertig

Frag einfach nach externen Zahlen, Marktdaten oder Wettbewerbern. Der Skill fragt sieben Leitplanken ab und legt einen Query-Plan zur Freigabe vor, bevor Geld fließt.

Wenn etwas nicht geht

macOS blockiert die Installer-App

Unsignierte Apps aus einem Download werden gesperrt. Dieser Befehl hebt die Sperre auf und startet sie.

A="$(find ~/Downloads ~/Desktop -maxdepth 3 -name "ROOTS Perplexity installieren.app" -print -quit 2>/dev/null)"; [ -n "$A" ] && xattr -dr com.apple.quarantine "$A" && open "$A" || echo "App nicht gefunden"

Nur das Plugin, Key ist schon da

/plugin marketplace add pgoutzeris-stack/roots-perplexity-recherche /plugin install roots-perplexity-recherche@roots-recherche

Key erneuern

/perplexity-key

Wieder entfernen

rm -rf ~/.roots/perplexity-key ~/.roots/mcp ~/.roots/node
